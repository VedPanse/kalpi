How the walk-in store was built

Type any Shopify store's address and walk through a 3D shop filled with its real products, photos and prices. These are the steps, in order, with the actual code from ~/calhacks-store.

TypeScriptthree.jsVitePython 3HTML + CSS
1

Find the products without asking anyone

Almost every Shopify store publishes its catalogue at /products.json, with names, prices, photos and variant IDs. No login or API key. I tested real stores first to make sure it works.

curl "https://homesick.com/products.json?limit=250"
# homesick.com 247 products · kyliecosmetics.com 250 · allbirds.com 250 · gymshark.com: hidden
2

A small Python helper to fetch it

A web page isn't allowed to read another site's data or use its photos as 3D textures (the browser's CORS rule). So a tiny server fetches the catalogue and passes the photos through. It uses only Python's standard library.

server/server.py
def products(domain):
    body, _ = fetch(f"https://{domain}/products.json?limit=250&page={page}")
    for p in json.loads(body)["products"]:
        v = p["variants"][0]
        out.append({
            "title": p["title"], "type": p["product_type"],
            "price": v["price"], "variant_id": v["id"],
            "image": p["images"][0]["src"],
        })

Only Shopify's image server is allowed through, so the helper can't be used to fetch random websites.

Describe a product once, in TypeScript

Every file agrees on what a product looks like. If a field is misspelled anywhere, TypeScript complains before the page even runs.

src/types.ts · src/api.ts
export interface Product {
  title: string; type: string; handle: string;
  price: string | null; variant_id: number; image: string;
}

export async function fetchStore(store: string): Promise<StoreData> {
  const res = await fetch('/api/products?store=' + encodeURIComponent(store));
  const data = await res.json();
  if (!res.ok) throw new Error(data.error ?? 'Could not read that store.');
  return data;
}
5

Draw signs and price tags in code

No image files needed. A 2D canvas draws the price tag, and three.js wraps it onto a small plane on the shelf edge. The aisle signs, checkout sign and floor tiles work the same way.

src/textures.ts
export function priceTexture(text: string) {
  return canvasTexture(256, 96, (g, w, h) => {
    g.fillStyle = '#FFFFFF';  g.fillRect(0, 0, w, h);
    g.fillStyle = '#E4002B';  g.fillRect(0, 0, w, 14);       // red strip on top
    g.fillStyle = '#111';
    g.font = '700 46px "IBM Plex Mono", monospace';
    g.fillText(text, w / 2, h * 0.6);                 // "$34.95"
  });
}
6

Build the store: as many aisles as the products need

One two-sided shelving unit holds 80 products (10 per shelf × 4 shelves × 2 sides). The code counts the products, makes that many units, sorts products by type so each aisle has a theme, and puts every product on a shelf two deep with a price tag in front.

src/store.ts
const LEVELS = [0.2, 0.62, 1.04, 1.46];   // shelf heights in metres
const PER_SIDE = Math.floor(UNIT_LENGTH / SLOT);  // 10
const PER_UNIT = PER_SIDE * LEVELS.length * 2;   // 80

products.sort((a, b) => a.type.localeCompare(b.type));   // themed aisles
const units = Math.ceil(products.length / PER_UNIT);

for (const depth of [0, 1]) {   // two facings deep, like a stocked shelf
  const box = new THREE.Mesh(productGeo, [edge, edge, edge, edge, photo, edge]);
  box.position.set(side * (UNIT_DEPTH - 0.09 - depth * 0.16), LEVELS[li] + 0.15, z);
  box.rotation.y = side * Math.PI / 2;          // face the aisle
  box.userData.product = p;                     // remembered for clicking
  unit.add(box);
}

The same file adds the end-of-aisle display, the hanging aisle signs (named after the most common product type), ceiling lights, the checkout counter, the entrance mat and two plants. All of it is built from boxes, cylinders, spheres and planes.

7

Walk around without going through shelves

The camera is your eyes, 1.6 m off the floor. Each frame, the keys decide where you'd move, and the move only happens if that spot isn't inside a shelf or outside the walls.

src/walker.ts
private free(x: number, z: number): boolean {
  if (x < b.x0 || x > b.x1 || z < b.z0 || z > b.z1) return false;  // walls
  return !this.blocks.some((o) => x > o.x0 && x < o.x1 && z > o.z0 && z < o.z1);  // shelves
}

const forward = (k.has('w') || k.has('arrowup') ? 1 : 0) - (k.has('s') || k.has('arrowdown') ? 1 : 0);
let dx = -Math.sin(this.yaw) * forward * speed;
let dz = -Math.cos(this.yaw) * forward * speed;
if (this.free(x + dx, z)) this.position.x += dx;   // slide along shelves
if (this.free(x, z + dz)) this.position.z += dz;

Checking x and z separately lets you slide along a shelf instead of getting stuck on it. Mouse look uses the browser's pointer lock, the same as a video game.

8

Click a product, or the floor

A raycaster shoots an invisible line from the camera through the mouse. If it hits a product, the product card opens. If it hits the floor, you walk there.

src/main.ts
ray.setFromCamera(ndc, camera);
const hit = ray.intersectObjects(world.pickables, false)[0];
if (hit && hit.distance < 7) {
  openPanel(loadedStore, hit.object.userData.product);   // product card
  return;
}
const f = ray.intersectObject(floor)[0];
if (f) walker.walkTo(f.point.x, f.point.z);              // click to walk
9

Real checkout links to the seller's store

Shopify supports "cart permalinks": a link with a variant ID drops that item straight into the seller's real cart. The product card uses it, so buying happens on their actual store.

src/api.ts
export function cartUrl(store: string, variantId: number) {
  return `https://${store}/cart/${variantId}:1`;
}

What we tried first, and why we changed course

  • Filming a room (Ved's Reframe). It worked, but 8 seconds of low-quality video gave a mesh full of holes, which looked too rough for a store.
  • AI image-to-3D for every product. Clean models, but about $0.30 each and a minute per product, and the fal balance was nearly used up.
  • What we kept: real product photos on real-looking shelves, the way InGallery does it. Instant, free, and every Shopify seller gets their own store. True 3D models can be added later for a few hero products.
