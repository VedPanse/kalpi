# Make app: the product and the store rooms in 3D

React + three.js. `src/LabelToShelf3D.jsx` is the product from the Label to Shelf plugin (its `VERSIONS` data: half-outlines in mm and label images). `src/StoreRooms3D.jsx` puts that product in four shop rooms. `src/App.jsx` switches between them.

Runs in a Figma Make file (attach the files and ask Make to use them; it installs `three`) or locally:

```sh
npm install
npm run dev
```
