# Kalpi

Ioanna's chosen Kalpi designs (23 Oct 2026). Open the gallery: `team-notes/design-options/favourites.html`.

Run from the repo folder so the 3D models and videos load:

```sh
cd kalpi
python3 -m http.server 8765
# open http://127.0.0.1:8765/team-notes/design-options/favourites.html
```

These are existing Kalpi design pages and models made before Cal Hacks, kept here as design reference.
