# Cost-approved Figma conversion

The primary Convert to 3D action exports the selected presentation board, obtains a free quote, and waits for explicit confirmation before any metered call. Hunyuan3D v3.1 Pro uses Normal + PBR; no custom face count or multiview surcharge. Price checked 24 October 2026: $0.375 + $0.15 = $0.525. gpt-4.1-mini identifies/crops the hero image and estimates dimensions (estimated below $0.01). UI rounds combined estimated $0.535 to about $0.54 USD. This is an estimate, not an account-wide spending cap. Recheck provider pricing before changing the quote version.

FAL_KEY and OPENAI_API_KEY are server-only. Spacetime service records store job ownership, quote acceptance, fal request ID and completion. Transactional claims prevent duplicate paid submissions. Status polling and import retries do not resubmit. Ambiguous submission outcomes block another generation for that creator/workspace pending reconciliation; inspect fal's dashboard before resolving the record. Never reset such a job to quoted automatically.

Generated models are private Blob assets registered to their workspace. Dynamic asset model references are permission-checked by Spacetime. Published snapshots grant access only to referenced assets while published. The importer accepts embedded GLBs from HTTPS fal.media, bounds download size, optimizes geometry/textures and creates a separate design. The source board is linked without replacing its artwork. Dimensions are estimates, not verified measurements. Generated meshes support dimension/material/artwork edits, not parametric silhouette editing or native vector reconstruction. Quality, fine lettering and unseen geometry are not guaranteed.

Verification: six workflow tests cover cost consent, double submission, uncertain outcomes, private jobs, free import retry and crop failure. Actual native plugin UI ran in a sandboxed simulated Figma host: cost, cancel, confirm, import and editor opening passed with mocked provider responses and a previously generated model. A real local Spacetime test rejects missing/cross-workspace model assets. Browser tests load private/public generated models, preserve textures and dimensions and export GLB. Import optimization of an existing 53.8 MB Hunyuan output produced 9.6 MB in ~0.7 s locally. No new paid generation was submitted. Actual Figma desktop and a fresh paid generation still require user execution.
